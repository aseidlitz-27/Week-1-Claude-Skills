# Skill: Accessibility (a11y) Compliance

## Mandatory Rules
- **Semantic Markup:** Use proper elements (`<button>`, `<a>`, `<header>`) instead of standard `<div>` wrappers for interactive features.
- **ARIA & Keyboard Navigation:** Ensure screen readers can read all elements and interactive parts are reachable via `Tab`.
- **Labels:** All inputs must have associated labels or `aria-label` attributes.
