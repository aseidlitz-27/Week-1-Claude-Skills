# Skill: Automated Testing Standards

## Context & Purpose
Ensure every feature, component, and utility function is thoroughly tested to prevent regressions and catch edge cases.

## Mandatory Rules
- **No Code Without Tests:** Every new feature or utility function must include corresponding unit or integration tests (using Jest/Vitest).
- **Edge Cases Required:** Tests must cover happy paths, error handling, null inputs, and boundary conditions.
- **Verification Rule:** Always run the test suite locally (e.g., `npm test`) to verify all tests pass before marking a task complete.
