# Project Engineering & Quality Standards

When writing, editing, or refactoring code in this repository, you MUST follow our modular skill guides located in `.claude/skills/`:

1. **User Experience:** Consult `.claude/skills/ux-standards.md` whenever building or editing UI components.
2. **Accessibility:** Consult `.claude/skills/accessibility.md` for all HTML/JSX elements and interactive components.
3. **Security:** Consult `.claude/skills/security-guard.md` when creating API endpoints, database queries, or handling user input.
4. **Testing:** Consult `.claude/skills/testing-standards.md` when writing features or utility functions to ensure full test coverage.
5. **Performance:** Consult `.claude/skills/performance-guard.md` when importing packages, writing data queries, or building client components.
